# Proposal

## Why

Issue #15 asks for a first piece of code in this scratch repository: a greeting function that callers can use to build a "Hello" message for a name. It gives the conductor loop a small, checkable task to plan and implement.

## What Changes

- Add a Python module at `src/greet.py`.
- The module provides `greet(name)`, which returns the string `Hello, <name>!`.

## Capabilities

### New Capabilities
- `greeting`: building a greeting message for a given name.

### Modified Capabilities

None.

## Impact

- New file `src/greet.py`; no existing code, APIs or dependencies change.
- Python standard library only.
